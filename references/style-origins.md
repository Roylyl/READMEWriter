# 设计来源

本技能根据用户提供的六个本地项目根 README 与 ASRtest 的远端 README 提炼写法，并参考 KunCode 的补充说明和 MacDuo 的运行说明。以下仅记录本次样本的文档设计特征，不声明这些项目当前功能或远端发布状态，也不要求使用者下载原仓库。

| 样本 | 提炼的写法 | 泛化时的处理 |
| --- | --- | --- |
| Clash Meta Plus | 120 px 图标、居中标题、徽章与导航；功能、设置路径、架构和构建表格 | 保留清晰步骤，代理配置、签名与派生关系只适用于相关项目 |
| DeerWebTranslator | 简洁用途说明、技术规格表、无需构建的安装流程、数据去向 | 先核实实际安装方式；避免把所有项目写成 npm 工程 |
| KunCode | 品牌区、发行入口、功能列表，用户安装与源码开发分离 | 不复制其品牌口号、平台承诺或安装包地址 |
| LENGHE-SoundShare | 多端规格、Mermaid 系统图、模块职责、分层验证 | 按复杂程度使用图表，保留“构建”和“实机验证”的区别 |
| MacDuo | 使用模式、菜单路径、默认值、权限与兼容范围 | 将限制放在实际受影响的操作旁，避免重复长篇声明 |
| [ASRtest](https://github.com/Roylyl/ASRtest/blob/main/README.md) | 居中图标与统一徽章、带图注的截图网格、模型矩阵、指标口径及证据索引 | 明确图片来源、参数单位、平台能力差异及测试覆盖范围 |
| Pet-Wei | 角色预览、规格与状态表、静态包结构、手动与自动安装入口 | 自动安装提示词只是示例资料，读取不等于执行授权 |

READMEWriter 是本次技能的交付目录，初始没有 README，因此没有把它计作已有风格样本。

共同风格是“品牌首屏 + 真实状态 + 快速操作 + 分层技术说明”。正文以正式中文、具体动词、短段落和必要表格为主。样本中的徽章数量、重复导航、长篇边界说明不视为硬性要求；技能保留风格并降低不必要的信息密度。

本包重新撰写通用规范，不复制样本正文、角色图像或项目 logo。

ASRtest 补充参考读取于 2026-09-23，以当时 main 分支的原始 README 为准；网页索引快照可能滞后。本记录仅提炼文档方法，不复制其版本、模型数量或性能结论。
