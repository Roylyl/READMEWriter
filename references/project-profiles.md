# 项目分类与检查目标

先从文件与入口判断主类型，再按需要叠加次类型。例如桌面 AI 客户端使用 Desktop App + AI Application；不因为目录名包含 app 就认定产品已经可用。

[机器可读分类表](project-profiles.json) 提供 15 类项目的四个字段。`required_sections` 表示完整重写时必须回答的信息，不强制同名标题；局部修改只检查相关部分。缺少资料时简洁说明未知或请求关键事实，不制造空章节。`recommended_sections` 按实际规模选择。`forbidden_assumptions` 是推断边界，不是禁止描述已验证的能力。`verification_targets` 指向应检查的文件或记录，不等于要求执行构建或硬件测试。

分类用于安排证据收集，不是依据标题数量评分。合并重复内容，优先读者的最短可用路径。

## Mobile App

- **必须回答：**平台与安装；核心流程；设备验证状态。
- **建议补充：**截图；权限；签名与构建。
- **不可默认推断：**最低部署版本等于全版本验证；模拟器通过等于真机通过。
- **证据检查目标：**部署目标；SDK；设备与模拟器记录；实际发行附件。

## Desktop App

- **必须回答：**系统与架构；安装启动与退出；验证范围。
- **建议补充：**权限；签名；更新与卸载。
- **不可默认推断：**可编译等于已签名公证；单架构等于全架构。
- **证据检查目标：**平台配置；打包脚本；签名记录；运行记录。

## Browser Extension

- **必须回答：**浏览器与扩展规范；加载步骤；权限与数据去向。
- **建议补充：**配置；截图；开发与测试。
- **不可默认推断：**Manifest V3 等于所有浏览器兼容；源码目录需要 npm 构建。
- **证据检查目标：**manifest；background/content 入口；host_permissions；真实加载记录。

## CLI

- **必须回答：**安装前提；最小命令与输出；参数或帮助入口。
- **建议补充：**配置；退出码；管道示例。
- **不可默认推断：**帮助文本等于参数已实现；包名等于包已发布。
- **证据检查目标：**命令解析器；入口注册；包清单；命令测试。

## Library / SDK

- **必须回答：**运行时要求；依赖安装；最小调用；API 入口。
- **建议补充：**错误处理；兼容矩阵；开发测试。
- **不可默认推断：**源码接口存在等于公开稳定 API；单次测试覆盖全部运行时。
- **证据检查目标：**包元数据；导出接口；测试环境；发布记录。

## Embedded Firmware

- **必须回答：**芯片与板型；工具链；构建烧录；验证状态。
- **建议补充：**引脚表；串口；恢复与升级。
- **不可默认推断：**编译成功等于可烧录；芯片家族等于任意开发板支持。
- **证据检查目标：**sdkconfig；板级定义；分区表；串口与实机日志。

## Hardware Project

- **必须回答：**硬件版本；原理图与 BOM 入口；供电及接口；原型状态。
- **建议补充：**装配；测量条件；设计文件格式。
- **不可默认推断：**仿真等于量产；BOM 存在等于已装配；估算等于实测。
- **证据检查目标：**原理图版本；BOM；网表；测量与装配记录。

## Hardware + Software System

- **必须回答：**系统边界；模块与链路；部署顺序；端到端状态。
- **建议补充：**协议矩阵；联调；故障定位。
- **不可默认推断：**单模块通过等于端到端通过；控制链路等于数据链路。
- **证据检查目标：**客户端和固件协议；版本清单；多端联调记录。

## AI Application

- **必须回答：**模型或供应商；运行配置；数据去向；费用边界。
- **建议补充：**示例；缓存；错误处理；模型选择。
- **不可默认推断：**兼容 API 等于模型可用；本地界面等于本地推理。
- **证据检查目标：**请求路径；配置；运行依赖；实际调用记录。

## Model Benchmark

- **必须回答：**模型矩阵；输入与环境；指标口径；复现与验证范围。
- **建议补充：**原始结果；资源体积；限制；许可。
- **不可默认推断：**模型文件大小等于内存；推理完成等于准确；模拟器耗时等于设备性能。
- **证据检查目标：**模型 revision；数据版本；计时起止点；原始结果；硬件记录。

## Dataset

- **必须回答：**来源与采集范围；结构；获取；使用许可与限制。
- **建议补充：**划分；标注；质量；版本与引用。
- **不可默认推断：**可下载等于可再分发；样本数等于唯一记录；无标签等于无偏差。
- **证据检查目标：**数据清单；校验和；字段样例；来源与许可；划分脚本。

## Agent Skill

- **必须回答：**适用任务；安装；调用；输出与范围；许可。
- **建议补充：**参考路由；校验；evals；生成内容许可。
- **不可默认推断：**装入目录等于已加载；lint 通过等于 Agent 效果已验证。
- **证据检查目标：**SKILL frontmatter；资源路径；脚本；真实或参考评估记录。

## Web App

- **必须回答：**运行依赖；本地启动；配置；服务与部署边界。
- **建议补充：**截图；数据库；测试；运维入口。
- **不可默认推断：**开发服务器等于生产部署；前端测试等于后端安全。
- **证据检查目标：**package scripts；环境模板；路由；服务配置；部署记录。

## Static Web Project

- **必须回答：**页面范围；预览；资源与发布方式。
- **建议补充：**浏览器行为；外部请求；维护入口。
- **不可默认推断：**静态网站必须 npm；缓存等于离线能力；源码存在等于已部署。
- **证据检查目标：**HTML/CSS/JS 入口；预览脚本；第三方资源；部署配置。

## Research Prototype

- **必须回答：**研究问题；原型范围；复现实验；证据与限制。
- **建议补充：**方法；实验设计；数据；后续问题。
- **不可默认推断：**概念演示等于产品；一次实验等于可泛化结论。
- **证据检查目标：**实验配置；原始记录；数据来源；代码与报告对应关系。
